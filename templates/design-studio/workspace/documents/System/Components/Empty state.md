What a screen shows before there's anything on it. One line on what will appear here, one action, and a small line illustration.

**Anatomy**

- Illustration (single-stroke, Ink Muted, decorative and hidden from screen readers)
- One sentence in Body, at most 64 characters
- One button

**States**

- First run (no plants yet), cleared (all care done today), filtered to nothing, offline

**Accessibility**

- The illustration is decorative; the sentence and the button carry everything
- The button is the first focus stop

**Acceptance criteria**

- [x] "No plants yet. Add your first one: a photo is enough." approved
- [x] "All done for today" uses Bloom for the small leaf, nothing else
- [ ] Offline variant copy in the UX copy sheet

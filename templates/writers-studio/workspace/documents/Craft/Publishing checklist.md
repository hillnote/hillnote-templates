# Publishing checklist

The last mile is where good pieces trip: a broken link, a subject line that gets cut off, an image with no description. This page takes a piece from **Ready** to **Published** without surprises.

## The day before

- [ ] All four passes of the [[Editing checklist|doc:documents/Craft/Editing%20checklist.md]] are done
- [ ] Headline, subtitle and email subject chosen; run `/headline_options` if you're stuck
- [ ] Preheader written: the 90 or so characters that show after the subject line
- [ ] Subject and preheader tried in the [[subject line preview|doc:documents/Pieces/Newsletter%20plan.md#subject-lines]] and saved to the piece
- [ ] Every image has a caption and alt text
- [ ] Every link opened and checked

## For the newsletter

- [ ] Paste into the email tool and check that headings and spacing survived
- [ ] Send a test to yourself and read it on a phone
- [ ] Schedule it for Friday at 7:30, so it's read with coffee rather than at lunch
- [ ] Add the issue to the run of issues in the [[Newsletter plan|doc:documents/Pieces/Newsletter%20plan.md]]

## For the site

Every newsletter essay also lives on the web, so new readers can find the back catalogue.

- [ ] Publish it to the blog: Hillnote turns the workspace into a site on your own domain, and the page keeps up when you edit the source
- [ ] Give the page a one-sentence description for link previews, under 155 characters
- [ ] The newsletter links to the web version, and the web version invites readers to subscribe to **${newsletter_name}**

## For a guest essay or prize

- [ ] The outlet's own style wins over yours: house spelling, how they handle titles and numbers
- [ ] Word count inside their limit, counted the way they count it
- [ ] Sent, then logged in **Pieces → Submissions** with the date, so the **Days out** column can tell you when to follow up
- [ ] For a prize judged anonymously: your name is nowhere in the file or the text

## For a book chapter

- [ ] Passes 1 and 2 done; passes 3 and 4 can wait for the editor's notes
- [ ] Sources listed at the end of the chapter, each linked to its row in **Reading notes**
- [ ] Sent to the editor with a three-line note: what changed, what you're unsure of, and what to read first

## After it goes out

- [ ] Move the row in **Pieces** to **Published** and set its publish date
- [ ] Reply to every reader reply within two days
- [ ] Copy the best line, and any good reader story, into the [[Commonplace book|doc:documents/Research/Commonplace%20book.md]]
- [ ] Add any new sparks to **Desk → Ideas**

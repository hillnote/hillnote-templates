# The special markers

| Marker | What it does |
| --- | --- |
| `~` | Adds vertical space |
| `~split` | Two columns side by side |
| `~inline` | Lays items in a row |
| `~banner` | Full-bleed section divider |
| `~bg-column-HEX` | Colours a column |
| `~text-column-HEX` | Sets text colour |
| `~bar` `~line` `~pie` | Charts the table below |

## ==Shortcuts are your best friend==

Hillnote has certain shortcuts outside of markdown syntax to help you supercharge your workflow

### The ‘/' command

It does one of 2 things

1. Helps you search for different formatting types
2. Allows you to directly send a question to AI
3. Ask documents a question by using ‘/’ + ‘@’

![Pasted image](resources/images/Pages/1780902206133.webp)

### The ‘@’ command

Helps you link a document to the page like this → [[Complete formatting guide|doc:documents/references/Complete%20formatting%20guide.md]] 

### The ‘#’ command

Helps you add topics like #formating-reference, etc

## ==Embed anything==

Simply use the ‘@’ symbol and link a Database, Slide or Canvas.  
You can also link a Weblink, Figma file and more by using the ‘/' command.

## ==Lock a page==

You can lock a page with a password. This encrypts the page and no one can read it, not even us.  
You need password to decrypt and the password is not stored anywhere. Click 3 dot menu in sidebar > lock with password to lock a document.

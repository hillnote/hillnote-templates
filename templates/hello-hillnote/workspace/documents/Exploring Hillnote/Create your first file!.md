## Start typing and create file or vice-versa!

![Pasted image](resources/images/Start%20here/1779089770347.webp)**You should get prompted by a new workspace screen**. You could either create your file first and then type or vice-versa by typing first and then pressing cntrl/cmd + save.

Once done there will be multiple avenues to explore and while [[Pages|doc:documents/Exploring%20Hillnote/Pages.md]] covers a large portion of the same. Some quick tips are

- to invoke the local model or formats **by using “/”**
- Select a section of text and pressing the ✨ button to fix grammer
- Select a section of text and use the custom prompt to feed in some info!

# App interface

The Desktop app is broken into two primary sections

1. **The Homsge** - The main landing page of the app. This is where you can navigate from one workspace to the next, setup your dashboard and more.
2. **The Workspace -** This is your workspace, this is the section when you enter a workspace and move within it.

The below sections cover the key sections of the interface.

:::toc "Table of Contents"
:::

# Home page

The home page is the main landing page when on the app. You can configure it to land either on the dashboard or workspaces view in settings.

The Home page has options in the top right to toggle between all of the available views.

![Pasted image](resources/images/App%20interface/1782849275789.webp)

## Workspaces

![Pasted image](resources/images/App%20interface/1782848634179.webp)The workspaces view is the default view when opening the app for the first time. Below is a breakdown of all of the sections available.

### Tags

Tags are easy ways to categorise your workspaces within tabs on the main page. These tags can help organise and make your workspaces easy to navigate.  
![Pasted image](resources/images/App%20interface/1782897978609.webp)  
**Adding a tag**  
Tagging a workspace is as simple as clicking the library icon at the top of a workspace while hovering on the same.  
![Pasted image](resources/images/App%20interface/1782897776939.webp)This then opens the tag dialog, select your tags or add new tags by using the input box within the dialog.  
![Pasted image](resources/images/App%20interface/1782897813725.webp)

### Synced Workspaces

One of the tabs available is “Synced”. This is where all synced workspaces appear including workspaces that you have been invited to collaborate on. Downloading a workspace from here makes it available in the main page and across your files.  
![](resources/images/App%20interface/1782897978609.webp)

### Create workspace

To create a workspace - click on the “create workspace tile”.

- You will be prompted to choose a location for it. You can save workspaces across your machine.
- Choose a name
- Add description to be used as the overarching context of why the workspace exists.

![Pasted image](resources/images/Start%20here/1779089344678.webp)

### Open workspace

To open a workspace click on “Open workspace” and locate your workspace folder. The name and description should auto populate within the dialog.

### Customising a workspace tile

To customise a workspace click the swatch icon. This then opens the swatch dialog for you to choose a colour or pattern to use as the background for the tile. You can choose between a colour, image or pre-set texture.  
![Pasted image](resources/images/App%20interface/1782898419590.webp)

### Removing a workspace

Deleting a workspace removes it from hillnote but leaves the local file as-is. This is to ensure deletion does not disrupt any other operations you have setup on the file. To completely remove a workspace delete it on Hillnote and then move the file to trash.

## Dashboard

The dashboard is a configurable hub for you to store all of the information across workspaces with options to setup widgets with just the right information designed and set by you.  
![Pasted image](resources/images/App%20interface/1782899676329.webp)

### Customising and building your dashboard

Make sure the dashboard is in its edit mode by clicking the edit dashboard button in the top right.

The dashboard rests on a grid that moves left to right. Click on the “Add widget” button to add a widget. We have a few options to choose from. Once added you can then proceed to construct the dashboard using the right combination of widgets you need.  
![Pasted image](resources/images/App%20interface/1782900278748.webp)

### Edit a widget

Once you add a widget hovering over the widget while in edit mode should show you the widget options  
![Pasted image](resources/images/App%20interface/1782900440560.webp)The options to the bottom left are the sizing options. The vertical bar helps set the height and horizontal bar sets the width.

The options to the top right are

1. The drag handle
2. Duplicate
3. Switch widget with another
4. Settings
5. Delete

You can edit a widgets contents by clicking on setting to open the edit widget panel as shown below.  
![Pasted image](resources/images/App%20interface/1782900570495.webp)

## Local AI

The AI tab allows you to manage your local models and download them. Hillnote runs on a version of Ollama and supports models across Ollama and Hugging face.  
![Pasted image](resources/images/App%20interface/1782971746123.webp)

### Downloading a model

Visit the handpicked tab to download a **handpicked model**  
![Pasted image](resources/images/App%20interface/1782971821356.webp)To download a **custom model** just copy the ollama command or the hugging face link and paste it in the appropriate input box  
![Pasted image](resources/images/App%20interface/1782971993574.webp)

## Settings

Most settings and methods to configure and customise hillnote are available in settings.

![Pasted image](resources/images/App%20interface/1782920589544.webp)

**Editor**: Customise the editor width, the theme, the landing page and toggle on and off interface elements in the editor.

A notable setting here is to choose your own emoji set for the documents and to enable and disable different CLI tools.  
![Pasted image](resources/images/App%20interface/1782959187976.webp)

**AI**: Allows you to set the model temperature and set its performance metrics

**Actions**: Customise the AI actions in the bubble menu. More information in [[Customise Hillnote|doc:documents/Exploring%20Hillnote/Customise%20Hillnote.md]] on the same.

**Templates**: Choose and customise the default templates available in the / menu. More information in [[Customise Hillnote|doc:documents/Exploring%20Hillnote/Customise%20Hillnote.md]] on the same.

**Memory**: Manage the memory snippets saved by AI as you work in the workspace.

**MCP**: Contains instructions and controls for the local and cloud MCP servers

**Hillnote**: Manage your dock icon options and shortcuts

**Advanced**: Manage system prompts and other advanced features. More information in [[Customise Hillnote|doc:documents/Exploring%20Hillnote/Customise%20Hillnote.md]] on the same.

## Workspace home

The landing page has 2 main modes. A document mode and a dashboard mode. You can choose the default by clicking on the settings icon in the page.  
![Pasted image](resources/images/App%20interface/1782964904505.webp)

### Documents

![Pasted image](resources/images/App%20interface/1782964803731.webp)This view combines a quick note module on top and a document tree below. You can also create a new file using the create module and clicking on the buttons below “Create something new” title.

The document tree allows you to filter and sort through all of the files in your workspace.

**Quick note:** Search for files or keep typing to save a quick document. You can format the document via AI before you save it.

### Dashboard

![Pasted image](resources/images/App%20interface/1782965412231.webp)Each workspace can have its own dashboard. It works similar to the main dashboard but all files are scoped to the workspace as defined above.

## Navigation

The side bar is where all files are listed and it has several modes and sections to choose from.

### File tree

By default the navbar shows all files in the workspace and allows you to navigate between them.

![Pasted image](resources/images/App%20interface/1782976282017.webp)

**Three dot menu** has a few options specific to the file. They are namely

1. Pin a file to the top (pictured below)
2. Rename a file
3. Share a file
4. Open to the left in a sidebar
5. Lock with password (see [[Pages|doc:documents/Exploring%20Hillnote/Pages.md]] )
6. Delete

**![Pasted image](resources/images/App%20interface/1782978591320.webp)**

### Workspace controls

Expanding the workspace dropdown should reveal all of the available workspace specific controls. They are namely  
![Pasted image](resources/images/App%20interface/1782978889178.webp)**Import File**: Import a multitude of files from PDF’s , excel sheets, word documents and more and add them to your workspace as markdown files.

**Tool forge:** Build custom tools and HTML files using tool forge and AI. Just describe the tool, choose a model and build the tool!  
![Pasted image](resources/images/App%20interface/1782979381426.webp)**Triggers:** Triggers help setup routines or actions in the server based on the your files changes and your workspace actions. These actions can be then setup at hillnote.com/dashboard. ![Pasted image](resources/images/App%20interface/1782979938894.webp)**Workspace settings:** Is the document registry to allow you to add descriptions or notes to files for models to know while traversing the registry. You also can prepare recipes here. Recipes are preset prompts to access via the ‘/' command in chat or in a document. They accept specific inputs and allow you to run a preset command with preset context.  
![Pasted image](resources/images/App%20interface/1782980077180.webp)  
**Refresh:** refreshes the file tree based on any external changes outside of hillnote.

**Clean up resources:** deletes any extra assets in the resources folder not currently used in the workspace.

### Sync

![Pasted image](resources/images/App%20interface/1782985509176.webp)The sync tab is where all of your sync related controls live. To sync a workspace you need first click on publish. Once published you can view all activity and begin using the sync tab.

1. **Changes** showcases all of the files changed. You can always select a file and discard changes.
2. **Activity** covers all activity both by you and the models
3. **Collaborators** allows you to add collaborators to the account. Collaborators are of 2 types. Admin and editor
   1. Admins can add other users and edit and work on files
   2. Editors can ONLY work on files and not add other users
4. **Settings** allows you to configure the sync settings.
   1. Auto publish eliminates the need for manual publishing and pushes your changes every 2 minutes.
   2. Storage show cases the storage remaining in your account.

## Top bar

The top bar is the main surface for all the tools you need while on your workspace.  
![Pasted image](resources/images/App%20interface/1782991215329.webp)

**Toggle navigation bar:** allows you to open and close the navigation sidebar to the left

**Source mode:** switches to show you the markdown version of your file

**Back and forward:** allows you to move to the previous file that you were on and the file that you navigated back from respectively.

**Search:** Allows you to search across the workspace for files, databases, etc to quickly navigate across.

**Sidebar options (configurable):** These are the buttons on the top right of the app. These buttons help open different tools in your sidebar and are configurable from settings.

## Side bar options

The list of notable sidebar options are as below

### Terminal

Opens a CLI panel on the right. If you have an existing Claude, OpenAI, Gemini, Cursor or Github copilot subscription you can open the CLI tools for the same to edit your files right from the terminal sidebar.  
![Pasted image](resources/images/App%20interface/1782993234720.webp)The sidebar has 3 main actions

1. Toggle light and dark mode
2. Clear all content
3. Open once of the CLI options (Claude, Gemini/antigravity, Cursor, Open AI, Github copilot). This however requires the installation to be completed as described in settings of the various CLI tools

The CLI tools will all be primed to point at your workspace and any agents run from your CLI will gain all context via the context files in the workspace.

### Tools

The tools panel allows you to open your tools from a central place. You can

1. **Tools:** View, manage and pin tools. Clicking on a tool opens the tool (more defined in [[Connect your tools|doc:documents/Exploring%20Hillnote/Connect%20your%20tools.md]] ).
2. Open a URL
3. Search wikipedia
4. open a PDF, image or other file as reference to the right.

![Pasted image](resources/images/App%20interface/1782993530615.webp)

### Side by side view

Open another document to the right of your current document to work on both files side by side.

![Pasted image](resources/images/App%20interface/1782994241082.webp)

### Chat

Chat is the main surface to converse directly with your team of AI agents. You can ask models to edit files, give you answers, create plans and more!

![Pasted image](resources/images/App%20interface/1782994816936.webp)  
**To switch models** click on the model icon and choose from the list of available models. ![Pasted image](resources/images/App%20interface/1782995203811.webp)  
**The text input** allows for images to be attached, toggling on and off tools (for local models) and web search. You can also switch between review edits and auto accept edits for models to skip asking for permission as they edit files. ![Pasted image](resources/images/App%20interface/1783001351997.webp)

‘/' commands work in the input to clear the conversation, switch models, compact the conversation. Any recipes in the workspace are also available here.  
![Pasted image](resources/images/App%20interface/1783001436848.webp)

Use the ‘@’ symbol to reference pages across the workspace as context.  
![Pasted image](resources/images/App%20interface/1783001450080.webp)

### Search and topics

You can search a document for a specific phrase or topic by pressing cmd/ctrl + F or by clicking the panel icon.  
![Pasted image](resources/images/App%20interface/1783002527596.webp)You can also click a topic to open the topics section. The topic section covers both documents that reference the topic and references within the document to traverse across.  
![Pasted image](resources/images/App%20interface/1783002577438.webp)

### Table of contents

Pressing Shift + Cmd/Ctrl + T opens the table of contents panel which categorises your headings into easy to traverse table of contents. Clicking on a heading in the panel will take you to the section in the page.

![Pasted image](resources/images/App%20interface/1783002752640.webp)

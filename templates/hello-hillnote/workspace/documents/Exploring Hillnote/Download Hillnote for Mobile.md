# Hillnote for mobile

Hillnote for mobile is a great way to continue using hillnote while on the move. It comes with the same principles as Hillnote - local file support, Access to local AI models, the same editor (defined in [[Pages|doc:documents/Exploring%20Hillnote/Pages.md]] ), [[Database|doc:documents/Exploring%20Hillnote/Database.md]] and more!

![Pasted image](resources/images/Hillnote%20for%20Mobile/1782825236639.webp)The mobile app features - 3 main tabs. Workspaces, Quick notes and chat.  
They are further detailed below.

## Workspaces

![Pasted image](resources/images/Hillnote%20for%20Mobile/1782824667769.webp)The primary surface for all of your work. You can

1. Create a workspace
2. Open an existing workspace from your files
3. Download a workspace that you may have synced (You will be prompted for a login if you are not signed in already)
4. Look at your tools, audio files and more.

### Navigating a workspace

![Pasted image](resources/images/Hillnote%20for%20Mobile/1782825654553.webp)**The workspace has 4 main options**

1. Quick note within the workspace
2. Search files (the file tree stays below)
3. Sync options (publish sends your changes to the cloud and pull brings all changes) - by default all changes are auto pulled in Hillnote periodically.
4. Add new file or folder
5. Clicking on a file opens the same.

### Tools

Tools can be accessed by clicking the 4th tab in the workspace overview. This lists all tools available in the workspace.  
![Pasted image](resources/images/Hillnote%20for%20Mobile/1782825860256.webp)

## Quick note

Quick note is the second tab in the app. Here you can record your thoughts, select the workspace this belongs to and click save to save the same.

All notes from this tab are saved to a quick notes folder within your workspace.  
![Pasted image](resources/images/Hillnote%20for%20Mobile/1782826008286.webp)

## Chat

The next tab is the chat tab where you can ask a model of your choice questions or ask it to complete tasks in your workspace like edit documents, retrieve information, etc.

![Pasted image](resources/images/Hillnote%20for%20Mobile/1782826447506.webp)

## The default markdown editor

All markdown files in your device can open on hillnote and be added to a workspace of your choosing.

![Pasted image](resources/images/Hillnote%20for%20Mobile/1782826559124.webp)

## Local Ai

On compatible devices with a local LLM present - Hillnote for mobile offers local AI assistance right within the editor. Both Apple Intelligence and Android AI (gemini, One plus AI, Samsung AI, etc) all work with hillnote. Just look for the sparkle icon when typing and click the same to switch to AI writing assistance.

![Pasted image](resources/images/Hillnote%20for%20Mobile/1782826810620.webp)

## Widgets

Hillnote ships with 3 widgets to pin to your phones home screen.  
They are

1. Quick note to open the app and start typing right away
2. Pin a note to read a note from Hillnote right on your home screen
3. Pinned tool to pin a tool to your Home screen for quick access
